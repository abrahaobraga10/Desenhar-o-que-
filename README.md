# Desenhar o quê?

Aplicação React criada para ajudar pessoas que não sabem o que desenhar. O projeto gera combinações de desafios envolvendo **paleta de cores**, **estilo artístico** e **material de desenho**, apresentadas por meio de cartas interativas.

> Projeto desenvolvido por **Abrahão Braga** para estudar React, consumo de APIs e outros conceitos fundamentais do desenvolvimento front-end.

## Demonstração

Acesse a versão publicada no GitHub Pages:

**[Clique aqui para acessar](https://abrahaobraga10.github.io/Desenhar-o-que-/)**

A tela inicial apresenta:

- Uma identidade visual voltada para desenho e criatividade;
- Cartas interativas com efeito de virar;
- Sugestões de paleta de cores, estilo artístico e material;
- Um botão para gerar um novo desafio;
- Layout adaptado para diferentes tamanhos de tela.

## Objetivos do projeto

Este projeto foi desenvolvido principalmente com fins de estudo. Durante sua construção, foram praticados conceitos como:

- Criação de interfaces com React;
- Organização da aplicação em componentes reutilizáveis;
- Gerenciamento de estado com Hooks;
- Navegação entre páginas;
- Consumo de API externa;
- Manipulação e exibição de dados recebidos de uma API;
- Uso de imagens, vídeos e outros recursos multimídia;
- Criação de layouts responsivos;
- Desenvolvimento de interações com CSS;
- Estruturação e documentação de um projeto front-end.

## Tecnologias e conceitos utilizados

- **React:** biblioteca principal utilizada para construir a interface por meio de componentes reutilizáveis;
- **JavaScript:** linguagem utilizada na lógica da aplicação, na manipulação dos dados e no controle das interações;
- **JSX:** sintaxe utilizada para estruturar os elementos visuais dentro dos componentes React;
- **React Hooks:** especialmente `useState`, para controlar estados como o comportamento de virar as cartas;
- **React Router DOM:** utilizado para criar a navegação entre as páginas da aplicação;
- **html2canvas:** biblioteca utilizada para capturar elementos HTML e exportar seu conteúdo como imagem;
- **CSS:** utilizado para criar a identidade visual, estilizar os componentes e organizar o layout;
- **CSS responsivo:** uso de media queries para adaptar a interface a diferentes larguras de tela;
- **Animações e transformações CSS:** uso de `transform`, `transition`, `perspective` e `backface-visibility` no efeito de virar as cartas;
- **Consumo de API:** estudo de requisições, recebimento de dados e exibição de informações vindas de uma API externa;
- **API da Wikipedia:** utilizada como fonte de informações e referências relacionadas a temas artísticos;
- **Recursos multimídia:** utilização de imagens, ícones e vídeos para complementar a experiência da aplicação;
- **Git e GitHub:** utilizados para versionamento, armazenamento e publicação do projeto.

## Como utilizar

1. Acesse a página inicial;
2. Clique nas cartas para revelar as opções;
3. Confira a paleta de cores, o estilo de arte e o material sugeridos;
4. Clique em **Gerar Desafio** para continuar;
5. Use a combinação recebida como inspiração para criar um desenho.

## Melhorias futuras

O projeto pode ser melhorado e expandido no futuro. Algumas possibilidades são:

- Implementar o consumo completo e dinâmico da API da Wikipedia;
- Permitir gerar novos valores sem recarregar a aplicação;
- Adicionar mais categorias de desafios;
- Criar um sistema para salvar desafios favoritos;
- Adicionar histórico dos desafios gerados;
- Melhorar a acessibilidade, incluindo navegação por teclado e atributos ARIA;
- Transformar os elementos clicáveis em controles semanticamente apropriados;
- Adicionar feedback visual durante o carregamento da API;
- Tratar erros de conexão e respostas inválidas da API;
- Melhorar a experiência em dispositivos móveis;
- Criar testes unitários e testes de componentes;
- Separar valores e estilos repetidos em constantes e variáveis CSS;
- Adicionar uma página de informações sobre o projeto;
- Criar novos temas visuais e opções de personalização;
- Melhorar a performance de imagens, vídeos e requisições;
- Adicionar suporte a outros idiomas.
